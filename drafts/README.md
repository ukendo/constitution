# Чернетки статуту

## Файли

| Файл | Роль |
|------|------|
| [`draft.md`](draft.md) / [`draft.docx`](draft.docx) | **Поточна** чернетка — саме тут диф у git між версіями |
| [`draft_rozbir.md`](draft_rozbir.md) | **Поточний** розбір щодо вимог |
| `draft_YYYY_MM_DD.md` (+ `.docx`, `_rozbir.md`) | **Знімок** на дату — для посилань і порівняння без git |

## Як оновити чернетку

1. Отримати нову версію (зазвичай DOCX).
2. Зберегти знімок: `draft_YYYY_MM_DD.docx` (і за потреби згенерувати `.md`).
3. Скопіювати вміст у **`draft.docx`** / **`draft.md`** (перезаписати поточні).
4. Оновити **`draft_rozbir.md`** під нову редакцію; за бажанням зберегти `draft_YYYY_MM_DD_rozbir.md`.
5. У PR описати, з якої дати знімок і що змінилось по суті.
6. Лінки на головній сторінці репозиторію мають вести на **`draft.md`** / **`draft_rozbir.md`**, не на датовані файли.

При розбіжності MD і DOCX пріоритет у **DOCX**, доки робоча група не вирішить інакше.
