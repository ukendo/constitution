# Чернетки статуту

У репозиторії **дві паралельні** редакції статуту (різні автори). Відстежуються окремо; жодна не «замінює» іншу автоматично.

| Гілка | Автор | Папка | Поточний текст |
|-------|--------|--------|----------------|
| **Кулик** | Євгенія Кулик | [`draft_kulyk/`](draft_kulyk/) | [`draft_kulyk/draft.md`](draft_kulyk/draft.md) |
| **Василенко** | Василенко | [`draft_vasilenko/`](draft_vasilenko/) | [`draft_vasilenko/draft.md`](draft_vasilenko/draft.md) |

Розбір кожної гілки щодо вимог — `draft_rozbir.md` **всередині** відповідної папки.

## Файли в кожній папці

| Файл | Роль |
|------|------|
| `draft.md` / `draft.docx` | **Поточна** чернетка гілки — тут git-диф між версіями *цієї* гілки |
| `draft_rozbir.md` | **Поточний** розбір цієї чернетки щодо вимог |
| `draft_description.md` (+ знімки) | Пояснювальна записка (є в гілці Василенко) |
| `draft_YYYY_MM_DD.md` (+ `.docx`, `_rozbir.md`) | **Знімок** на дату в межах гілки |

## Як оновити одну з гілок

1. Взяти нову DOCX-версію відповідного автора.
2. Зберегти знімок у **його** папці: `draft_YYYY_MM_DD.docx` (+ `.md`).
3. Перезаписати **`draft.md` / `draft.docx`** у тій самій папці.
4. Оновити **`draft_rozbir.md`** (бажано з дельтою vs попередній знімок *цієї* гілки); зберегти `draft_YYYY_MM_DD_rozbir.md`.
5. Не змішувати файли Кулик ↔ Василенко без явного рішення в PR.
6. У корені репозиторію лінки ведуть на **обидві** поточні `draft.md`, не на датовані знімки.

При розбіжності MD і DOCX пріоритет у **DOCX**, доки робоча група не вирішить інакше.
